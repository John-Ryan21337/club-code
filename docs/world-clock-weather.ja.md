# 世界時計＆お天気ウィジェット 🌃🕰️✨

Club Code の Electron 版でも、認証済みのブラウザ／LAN 画面でも、透け感たっぷりの世界時計を
出せます。初期設定はオフ。つまり、勝手に「東京いま何時〜？」とは始まりません。そこは空気を
読む子です🍸

## 設定するわよ〜💅

**設定 → 外観 → 世界時計＆お天気** を開いてください。

- ウィジェット全体のオン／オフ
- **レインボーシマー**、**琥珀色ニキシー管**、**透明アナログ**、
  **昔ながらの LED** の4スタイル
- 1〜6都市を選択。各都市には IANA タイムゾーンが明示されているので、サマータイムも
  ブラウザのタイムゾーン情報に従います
- 現在のお天気は任意でオン

時刻は Club Code 共通のロケール／12時間／24時間設定に従います。見た目と都市の設定は
設定プロファイルに入りますが、位置・サイズ・折りたたみ状態・お天気通信への同意は
ブラウザ／Electron ごとにローカル保存します。同意は接続中の別クライアントへ同期せず、
設定プロファイルにも含めません。各画面で個別にオンにしてください。

グリップで移動、右下のハンドルでリサイズ、山形ボタンで折りたたみ。キーボードの矢印でも
調整できて、Shift＋矢印なら1ピクセルずつ。狭いスマホ画面でも画面外へ逃げないように
収まります。折りたたみ中または画面非表示中は、時計更新、Matrix 配色の購読、お天気通信を
止めます。休むときは休む、歌舞伎町でも大事な作法です😴

## お天気通信・プライバシー（重要）

お天気機能は初期設定で無効であり、利用者が明示的に有効にした場合だけ通信します。有効に
すると、選択した都市の座標と端末／ブラウザのネットワーク IP アドレスが、公式の
[Open-Meteo Forecast API](https://open-meteo.com/en/docs) へ直接送信されます。プロンプト、
プロジェクト、プロバイダー、アカウント、ワークスペースのデータは送信しません。Club Code
の認証情報も使用しません。

Open-Meteo の API キー不要の無料エンドポイントは非商用利用に限定され、CC BY 4.0 に基づく
帰属表示とレート制限があります。同社の規約では、トラブルシューティング用ログに IP
アドレスと要求した座標が含まれる場合があり、ログは90日後に削除されます。商用利用者は、
Club Code が適切な有料エンドポイントに対応するまで、この無料お天気機能を無効のままに
してください。有効にする前に、最新の
[Open-Meteo 利用規約](https://open-meteo.com/en/terms) と
[料金／API プラン](https://open-meteo.com/en/pricing) を確認してください。

通信とエラーの境界は次のとおりです。

- 最大6都市を1回の HTTPS リクエストにまとめます。
- 正常な観測値は15分間キャッシュし、同一内容の同時通信は1本にまとめます。
- 8秒でタイムアウトし、レスポンスは64 KiBまでです。
- 更新に失敗して以前の観測値を表示する場合は、必ず **stale（古い情報）** と表示します。
- 使用可能な観測値がなければ **Weather unavailable** と表示し、再試行は最短でも5分後です。
- 天気状態は提供元の WMO 天気コード分類です。遅延、不完全、不正確、利用不能の可能性が
  あります。
