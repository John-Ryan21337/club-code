# Synthetic database discovery

These images and the 6.68-second recording show the actual workspace observatory, discovery control and database viewer with a synthetic environment API. The fixture performs an explicit scan, selects an extensionless path, then loads synthetic tables and rows. It does not scan a user workspace or prove the backend scan through the video.

The final partial-result text matches the reviewed component. `interaction.webm` is 253,053 bytes; it was decoded and a frame inspected after capture. Temporary fixture modules, configuration and duplicate recordings were removed. Separate server tests use temporary generated SQLite files and the authenticated WebSocket path.
