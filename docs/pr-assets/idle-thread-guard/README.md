# Idle Thread Guard review media

The screenshots render the real `IdleThreadGuardControl` in a small synthetic thread/composer frame. `before.png` shows that frame without the new control; it is not a screenshot of a running Cafe installation. `after.png` shows the actual enabled six-hour control. `bilingual.png` shows its English/Japanese labels and built-in prompt draft.

The video runs the real control regression: expand, reject a zero-hour value, edit a custom request, enable, and disable. It uses browser-local synthetic environment/thread IDs and real local storage. No provider is called. The coordinator is not mounted in these media fixtures, so enabling this preview cannot submit a request.

The temporary capture fixtures and configuration were removed after capture. The permanent control and coordinator browser tests cover behavior; these media show appearance and interaction only.
