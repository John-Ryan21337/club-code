# Synthetic row comparisons

The images and unedited 7.36-second recording show the actual observatory and database viewer with synthetic API responses. The fixture loads a first snapshot, explicitly refreshes to a second one, displays changed/new/missing preview rows, and starts then stops the optional refresh toggle. The recording was decoded to completion and its final frame inspected. It is 383,615 bytes at 1280 × 950.

This media demonstrates the renderer, not a user database or the SQL worker. Separate temporary SQLite and authenticated WebSocket tests cover that path. No user database or account was read. Temporary capture source, configuration and duplicate recording were removed.

画像と 7.36 秒の未編集動画は、合成 API を使った実際の観測画面とデータベース表示です。最初の表示を読み、明示的に更新して、変化・今回のみ・前回のみの行を示します。任意の自動更新を開始して停止します。動画を最後まで復号し、最後のフレームを確認しました。実際のユーザーデータベースや SQL 処理を動画で証明するものではありません。SQL と認証済み WebSocket は別の合成検査で確認します。
